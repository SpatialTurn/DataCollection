# Notebooks for CyberFaCES

These are copies of the notebooks in `../notebooks/`, made for the CyberFaCES Jupyter workspace
(https://cyberfaces.org). They open in the **SpatialTurn GIS** kernel, their "Next" links stay inside this
folder, and their first cell links to the Google Colab version.

Do not edit these files by hand. They are generated from `../notebooks/` by `notebook_copies.py` in the
SpatialTurn build scripts; edit the notebook builder, rebuild `../notebooks/`, then rerun `notebook_copies.py`.
